# BIOBUZZ 2026-27 — KLA 코드 정리

## 구조
```
KLA/
├─ Teleop/  Blue, Red         ← 진영 + 리셋 위치만 다름
│           AllianceTeleop    ← 공통 (버튼·기능 전부 여기)
├─ Auto/    BlueFinal, RedFinal
└─ Util/    Drive          주행
            Action         슈터·인테이크·블로커·플라워·후드
            TurretAim      터렛 자동 조준 (PID)
            ShotTable      거리 → 후드 표
            Alliance       진영별 셀 좌표, 목표 셀 선택
            PoseStore      오토 끝 위치 → TeleOp 넘김
            HubLed         허브 LED (무지개 / 준비되면 초록)
```
`no/` 폴더는 테스트·옛날 코드 (`@Disabled`로 숨김).

### gamepad2 (오퍼레이터)
| 버튼 | 기능 |
|---|---|
| **RT 누르고 있기** | 발사: 블로커 열림 → 슈터 목표 속도 도달 시 인테이크 자동 급탄 → 놓으면 정지·예열 복귀 |

## 자동 기능
- **터렛 자동 조준**: Pinpoint 위치로 셀 방향 계산 → PID.
  - y 70.75 기준으로 로봇과 같은 쪽 셀을 조준 (블루: 위 = Garden, 아래 = Flower / 레드는 반대).
  - ±200° 리밋, 뒤로 넘어갈 때 한 바퀴 도는 것 방지.
  - init 때 터렛 방향 = 0°.
- **거리별 후드**: 셀까지 거리 → `ShotTable` 곡선 맞춤으로 후드 결정. 슈터 속도는 `SHOOTING_VELOCITY` 고정.
- **연발 후드 보정**: 연사 중 슈터 속도가 떨어진 만큼 후드를 올림 (0.80 ~ 0.97).
- **슈터 예열**: 평소 `IDLE_VELOCITY`로 계속 회전.
- **슈터 전압 보정**: 배터리 전압에 맞춰 F 자동 조정.
- **발사 준비 알림**: 슈터 속도 도달 + 터렛 오차 2° 이내 → 오퍼레이터 진동, LED 초록, 텔레메트리 `READY`.
- **오토 위치 이어받기**: 같은 진영 오토가 끝나고 120초 안에 TeleOp을 시작하면 오토 끝 위치에서 시작.
- **허브 LED**: 평소 무지개, 준비되면 초록, OpMode 끝나면 원래 색.

## 오토 (BlueFinal / RedFinal)
```
START → 서보 초기 위치 → 0.3초 대기
→ ① 제자리 발사
→ ② 플라워 열고 인테이크 → shotgointake → flowerintake → 대기
→ ③ 이동하며 예열 → goshot → 발사
→ ④ gointake → flowerintake_2 → 대기
→ ⑤ 이동하며 예열 → goshot_2 → 발사 → 플라워 닫기
→ ⑥ 주차
```
- 발사: 슈터 목표 속도 도달까지 대기 → 인테이크 0.7로 급탄.
- 터렛은 0°에 고정, 조준은 로봇 방향으로.
- 매 루프 위치를 `PoseStore`에 저장 → TeleOp이 이어받음.
